# openX site

Static site for the openX Windows host. No build step, no framework, no
JavaScript required to read it. Everything here is served as-is.

## Preview / publish with a temporary URL

```bash
./serve.sh            # http://127.0.0.1:8787 + a trycloudflare.com URL
PORT=9000 ./serve.sh
```

`serve.sh` starts `python3 -m http.server` and a Cloudflare **quick tunnel**
(no account needed). The `https://…trycloudflare.com` address is public while
the script runs and changes every time it starts. The first run downloads
`cloudflared` into `.tools/` (git-ignored).

## Permanent hosting

Upload the contents of this folder (not the folder itself) to any static host:

- **Cloudflare Pages** — `npx wrangler pages deploy . --project-name openx`
- **GitHub Pages** — push these files to a repo and enable Pages
- **Netlify / Vercel** — drag the folder in, or `netlify deploy --dir . --prod`
- **Any web server** — copy the files; there is no server-side code

Keep the folder layout intact so `download/openX-1.0-win64.zip` and
`assets/*.png` keep resolving.

## Files

| Path | What it is |
|---|---|
| `index.html` | landing page |
| `docs.html` | install, editor, autoexec, files, troubleshooting |
| `styles.css` | the whole design |
| `assets/ui-*.png` | screenshots rendered from `preview/app.html` |
| `preview/app.html` | HTML replica of the WinForms UI, used to make those shots |
| `download/openX-1.0-win64.zip` | release archive (no core DLL included) |
| `download/SHA256SUMS` | checksum of the archive, regenerated by `serve.sh` |
| `serve.sh` | local preview + temporary public tunnel |

## Regenerating the screenshots

The three PNGs come from the HTML replica at 1180 × 780, so the site matches
the real layout:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --force-device-scale-factor=2 \
  --window-size=1180,780 --hide-scrollbars --virtual-time-budget=2500 \
  --screenshot=assets/ui-editor.png \
  "file://$PWD/preview/app.html?v=editor"
```

Use `?v=console` and `?v=setup` for the other two. Keep `preview/app.html` in
sync with `src/openX/UI/MainForm.cs` when the layout changes.
